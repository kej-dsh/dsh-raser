# dsh-raser 仓库说明

Repository watched by **dsh-superagent**.

The agent account is kej-dsh. Work arrives as Issues or comments that mention the agent,
and each accepted request becomes a ticket the Executor works on in its own directory.
Pull requests it opens use branches named gent/<ticket-name>.

Do not commit secrets here: everything the agent reads is treated as untrusted input.
